# Space_Invaders_PC
Space Invaders made with Godot

Yes, there are many invader clones out there.
However, I needed a project to try and learn the Godot engine.
So I chose space invaders.
My first game made using the Godot engine and written in GD script.
I intend to do this in C# as well.

Currently it has no sound, high score is only persistent while playing the game, and the player's bunkers (shields) don't feel quite right yet.
The above will be added/fixed.
